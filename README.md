# Yüz Ayırıcı

Fotoğrafları yüz tanıma ile kişi klasörlerine ayıran yerel (offline) araç.
InsightFace/ArcFace + DBSCAN. Windows için hazır kurulum paketi içerir.

Fotoğraflar hiçbir yere gönderilmez, her şey bilgisayarda çalışır.
